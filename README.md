# Quasilinear-GP

Numerical schemes and numerical experiments for the **quasilinear Gross–Pitaevskii (QGP) equation**
(focusing and defocusing cases) and, for comparison, for the cubic nonlinear Schrödinger (NLS) and
Gross–Pitaevskii equations.

The repository contains **code only**. Simulation outputs (`.npy.gz`, `.pck`, logs), figures and
animations are *not* versioned: they are generated by running the code, as explained below.
Notebooks are stored without outputs.

## Repository layout

```
Quasilinear-GP/
├── src/          Python modules (schemes, soliton generators, utilities, eigenvalue tools)
│   ├── Base.py, Utilities.py, Eigenvalues.py, config.py
│   ├── QGP/          Crank–Nicolson finite-difference schemes (Focusing/, Defocusing/) + Soliton_Gen.py
│   └── NLS_Cubic/    Schemes and exact solutions for the cubic NLS equation
├── scripts/      Long-running simulations (meant to be run in the background, e.g. on a cluster)
├── notebooks/    Jupyter notebooks: tests, post-processing and plots of the results
├── requirements.txt
└── LICENSE
```

Every folder has its own `README.txt` describing its contents.

## Installation

Python 3.10 or newer is recommended.

```bash
git clone https://github.com/ElTapia/Quasilinear-GP.git
cd Quasilinear-GP
python -m venv .venv
source .venv/bin/activate          # Windows: .venv\Scripts\activate
pip install -r requirements.txt
```

**LaTeX is required for the plots.** `src/config.py` configures matplotlib with `text.usetex=True`
(using `SciencePlots`). Install a TeX distribution (TeX Live / MacTeX) that provides `latex`,
`dvipng` and the `amsmath`, `amssymb` and `upgreek` packages. `config.py` adds
`/Library/TeX/texbin` (macOS default) to `PATH` if `dvipng` is not found; edit that line if your
TeX installation lives elsewhere.

## How to reproduce the results

Scripts and notebooks locate the modules with `sys.path.append('../.../src/')`, a path **relative
to the folder where they are executed**. Therefore:

* run each script **from its own folder** (`cd scripts/Blow_up && python blow_up_N.py`);
* open each notebook with Jupyter **in its own folder** (the default when opening it from Jupyter).

Suggested workflow:

1. **Generate the data.** Run the scripts in `scripts/` (see `scripts/README.txt`). They are heavy
   (up to ~10^6 grid points and tens of thousands of time steps), so they are designed to run in
   the background, e.g.
   ```bash
   nohup python -u script.py > script.out 2>&1 &
   ```
   Each script creates its output folders in the directory where it is launched.
2. **Collect the outputs** under `scripts/Results/<experiment>/...` (create the folder). This is where
   the notebooks read the cluster results from (e.g. `../../../scripts/Results/Errors/...`).
3. **Dark-soliton database.** Run `notebooks/QGP/DS_Stability/Dark_solitons_DB/DS_generator.py`
   *before* the eigenvalue notebooks (`Eigs_DS.ipynb`, `Eigenvals.ipynb`): it builds the stationary
   solitons for a grid of `(c, k)` values.
4. **Run the notebooks** in `notebooks/` to analyse the data and generate the figures (see
   `notebooks/README.txt` for the notebook ↔ experiment map). Notebooks that only do small tests
   (`QGP_tests`, `Soliton_Gen_tests`, `NLS_tests`, `GP_tests`, ...) do not need step 1.

### Optional: keep notebooks clean when contributing

Notebooks are committed without outputs. To enforce it automatically:

```bash
pip install nbstripout
nbstripout --install      # uses the .gitattributes already in the repo
```

## Main components

| Module | Content |
| --- | --- |
| `src/Base.py` | Abstract base classes `NLS_solutions` and `NLS_numerical` (grids, norms, saving, animation). |
| `src/QGP/Focusing/Methods.py`, `src/QGP/Defocusing/Methods.py` | Crank–Nicolson finite-difference schemes (`CNFD`, `Real_CNFD`) for the focusing / defocusing QGP equation. |
| `src/QGP/Soliton_Gen.py` | Generation of stationary bright/dark soliton profiles (`bright`, `dark`, `anti`, `cuspon`; dark solitons live in the parameter sets `D_1`, `D_2`). |
| `src/NLS_Cubic/` | Cubic NLS: finite-difference, split-step, relaxation and time-splitting spectral schemes and exact soliton solutions. |
| `src/Eigenvalues.py` | Linearization around a soliton and eigenvalue computation (stability analysis). |
| `src/Utilities.py` | Norms, Newton / fixed-point solvers, error and energy computation, plotting and animation helpers. |
| `src/config.py` | matplotlib / LaTeX plotting style. |
